## 📚 Temari i Pràctiques

- **Pipeline Gràfic d'OpenGL 3.3 Core Profile:**
  - Vertex Array Objects (**VAO**) i Vertex Buffer Objects (**VBO**).
  - Programació de shaders en **GLSL**: Vertex Shader (`.vert`) i Fragment Shader (`.frag`).
- **Transformacions Geomètriques i Càmeres:**
  - Matrius de model, vista i projecció (MVP).
  - Càmeres en perspectiva i ortogràfiques amb control d'angles d'Euler.
- **Interfícies d'Usuari amb Qt:**
  - Integració de widgets OpenGL (`QOpenGLWidget`, `QOpenGLFunctions_3_3_Core`).
  - Sistema de senyals i ranures (*signals & slots*) per a controls interactius.
